# LeafMC-Pterodactyl-Egg
A simple Pterodactyl egg i made for LeafMC, which is a A Paper fork aim to find balance between performance, vanilla and stability.

Installation steps are really easy

* Open your admin panel on Pterodactyl,
* Navigate to "Nests",
* Click "Import Egg" and select the json that you can download from my repo,
* Done ✔️ Now when create a new Pterodactyl server, the "LeafMC" egg will be on the drop menu.
